# 🏔️ AMS Risk Predictor — Streamlit App

Streamlit deployment of the **Logistic Regression** AMS susceptibility model, trained on baseline transcriptomic + physiological features.

---

## 📁 Project Structure

```
ams_streamlit/
├── app/
│   └── app.py              ← Main Streamlit application
├── models/                 ← Place your .pkl model files here
│   └── final_model_LR.pkl  ← Generated by Notebook 4, Section 16
├── requirements.txt
└── README.md
```

---

## 🚀 Setup & Run

### 1. Copy your trained model

Copy the serialised model from your notebook outputs:

```bash
# From your ams_pred project folder:
cp ams_pred/models/final_model_LR.pkl ams_streamlit/models/
```

### 2. Install dependencies

```bash
cd ams_streamlit
pip install -r requirements.txt
```

### 3. Run the app

```bash
streamlit run app/app.py
```

The app will open at `http://localhost:8501`

---

## 🌐 Deploy to Streamlit Community Cloud (free)

1. Push this folder to a **GitHub repository**
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your repo and set:
   - **Main file path:** `app/app.py`
   - **Python version:** 3.10+

> ⚠️ The model `.pkl` file must be committed to the repo (or loaded via a secrets-based cloud storage path).

## 📋 App Features

### Tab 1 — 🔮 Predict (Single Subject)
- Manual input of physiological parameters (PaO2, PaCO2, SaO2, CaO2, P50, Hemoglobin, Sex)
- Gene expression input panel (expander with all model gene features)
- Real-time AMS risk prediction with probability score
- Feature contribution bar chart (LR coefficients × scaled values)

### Tab 2 — 📊 Batch Predict (CSV)
- Download feature template CSV
- Upload filled CSV for multiple subjects
- Batch predictions with probability scores and risk levels
- Summary distribution plots
- Download results CSV

### Tab 3 — 📈 Model Info
- Pipeline summary and LOOCV performance table
- RF vs LR comparison table
- Feature engineering details
- Global feature importance (LR coefficients plot)

### Tab 4 — 📋 About
- Full project pipeline overview
- Cohort description
- Clinical applications and limitations

## 🔑 Model File Format

The app expects `final_model_LR.pkl` — a pickle dict produced by Notebook 4, Section 16:

```python
{
    'model':         fitted LogisticRegression,
    'imputer':       fitted SimpleImputer,
    'scaler':        fitted RobustScaler,
    'feat_names':    list of feature column names,
    'model_name':    'LR',
    'modal_params':  {'C': ..., 'penalty': ...},
    'loocv_metrics': {'auc_roc': 0.868, 'sensitivity': 1.0, ...},
}
```
